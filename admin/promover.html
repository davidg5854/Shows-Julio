Promover a producción

Esto lleva lo que probaste en staging a la web real (julioalfonzo.com), a través de un PR.

  1. Tocá el botón: se abre GitHub con el PR ya armado (de staging a main).
  2. Dale “Create pull request”.
  3. Después “Merge pull request” → “Confirm merge”.
  4. En 1-2 min la web real queda actualizada. ✅
Crear PR de promoción → Ver primero el sitio de prueba ↗ ← Volver al panel

¿No hay nada para promover? Significa que staging y producción ya están iguales (no hay cambios pendientes). 👌
